# RE:Dream 프로젝트 점검 요약

기준일: 2026-09-27

## 점검 범위

프로젝트 설정, 패키지, 빌드 씬, 게임 스크립트, UI·오디오·아트·영상 에셋과 기존 검증 기록을 확인했다. 이번 작업에서 Unity Editor 실행, 새 컴파일, 실행 파일 빌드, 전체 플레이와 청음은 수행하지 않았다. 발표 장표의 화면은 프로젝트에 보관된 기존 게임 캡처 및 실제 원화다.

## 현재 구현

- 병실에서 환자와 상호작용해 꿈으로 진입하는 흐름.
- 챕터 1: 네 단서 조사, 정화총 획득, 몬스터 정화와 유니콘 보스 약점 전투.
- 챕터 2: 세 스테이지, 손전등과 숨겨진 위험, 점프·벽차기·대시, 보스 두 페이즈와 재시도 처리.
- 엔딩: 동생 등장 8프레임과 대화, 32.9초 병실 에필로그, 메인 메뉴 복귀 코드.
- 공통: 로딩, HUD, 대화, 일시정지, 챕터별 UI 스킨, 음악 전환.
- 단서 음성 MP3 5개와 정원·보스·엔딩 음악 파일 및 호출 코드가 현재 존재한다. 과거 오디오 문서의 누락 표시는 최신 상태와 다르다.

## 기술 구성

- Unity 6, 6000.3.21f1 / C# / Built-in Render Pipeline.
- Input System 1.11.2, AI Navigation 2.0.14, Cinemachine 3.1.7, uGUI 2.0.0.
- Assets/Scripts 아래 런타임 C# 파일 156개, 에디터 파일 21개. 기능별 MonoBehaviour와 일부 ScriptableObject 중심 구성.
- 빌드 설정의 활성 씬 8개: MainMenu, Loading, Game, HospitalRoom, SD_BrightDream_Blockout_Rect, BadDream_Stage1, BadDream_stage2, BadDream_Stage3.
- 제작 원본과 기록은 ArtSource, 게임 적용 결과는 Assets에 보관한다.

## 기존 검증에서 확인된 것

- 2026-09-25 손전등 32개 상태 조합 검사 기록.
- 보스 일반 변신과 2페이즈 재시도의 크기 일치 검사 기록.
- 유니콘 약점 규칙 및 UI 상태를 직접 설정한 검사 기록.
- 챕터 1 다리 충돌면, 이동 경로, 손과 보스 접촉점 관련 검사 기록.

이는 해당 시점의 개별 검사다. 최신 변경을 포함한 전체 완주와 빌드 통과를 의미하지 않는다.

## 시연 전 확인할 항목

1. Unity에서 최신 동생 프레임의 연속 재생, 발밑 고정, 플레이어 대비 크기와 마지막 대화 연결을 확인한다.
2. 처음부터 엔딩까지 완주하고 사망·재시도·체크포인트·메뉴 복귀를 점검한다.
3. 엔딩 영상 재생과 스킵, 음악 전환 및 음성 볼륨을 실제로 듣고 확인한다.
4. 제품명 noname과 회사명 DefaultCompany를 배포 이름으로 정리한다.
5. 실제 실행 빌드를 생성하고 별도 실행 환경에서 확인한다. 저장소에서 전용 자동 테스트 구성은 확인하지 못했다.

## 자료 해석 주의

BOSS_DESIGN.md 등의 과거 설계 문서는 현재 구현과 일부 다르다. 발표 자료는 현행 소스와 에셋을 우선했다. 패키지 캐시 없이 해결되지 않는 Unity/uGUI GUID를 누락 스크립트로 단정하지 않았다. 각 슬라이드의 발표자 노트에 근거 파일 경로를 기록했다.
