## 바로 쓰는 법

임포트해서 그대로 놓으면 된다. 스케일 조정도, 원점 이동도 필요 없다.

- 최장축 0.220 m (몹 0.900 m 기준 손에 드는 크기)
- 원점 바닥 중앙 (Y = 0)
- 3,000 tris / 텍스처 1024 3장

## 커밋하지 않은 것

**VARCO 원본 GLB (20,000 tris / 텍스처 2048, 합계 112 MB) 는 리포지토리에 없다.**
납품본으로 충분하고 LFS 용량을 아끼기 위해서다. 재작업이 필요하면
`00_docs/gun_prompts.md` 의 프롬프트로 다시 생성하거나, 워크플로 세션에서
내려받은 뒤 `00_docs/cleanup_for_game.py` 를 다시 돌리면 된다.
