# 벽면 장식 에셋 20종 (납작한 부직포 컷아웃)

펠트 교구(felt activity board)처럼 **얇은 부직포 조각을 오려 겹친** 스타일.
두께는 3~10mm 고정이고 부피감이 전혀 없다.

## 기존 varco-wall 과 다른 점

기존 세트는 통통하게 속을 채운 펠트 인형 느낌이었다. 이번 것은 방향이 반대다.

| | 기존 varco-wall | 이번 wall-flat |
|---|---|---|
| 형태 | 속 채운 입체 | 오려 붙인 납작한 조각 |
| 두께 | 수십 cm ~ m 단위 | **3 ~ 10 mm** |
| 제작 | VARCO Generate3D | 이미지 실루엣 → Blender 압출 |
| 폴리곤 (20종 합계) | 104,018 tris | **11,183 faces** |
| 용량 | 4.7MB | 1.5MB (GLB) |

## 왜 VARCO 3D 를 쓰지 않았나

평면을 위에서 찍은 이미지에는 두께 정보가 없다. 그 상태로 3D 변환기에 넣으면
두께를 추측해서 큐브처럼 부풀려 버린다. 예전에 `01_wall_sky_panel` / `02_wall_corner`
가 통째로 상자가 되었던 이유가 이것이다.

그래서 이번에는 **이미지에서 실루엣만 따서 Blender 에서 직접 압출**했다.
두께를 코드가 정하므로 "얇게"가 100% 보장된다.

## 파일

- `out/wall_flat_felt.blend` — 20종 전부, 텍스처 내장 (8.3MB)
- `out/wall_flat_felt.glb` — Unity 등으로 바로 가져갈 수 있는 형태 (1.5MB)
- `src/` — VARCO 원본 이미지 1024 (36MB, 리포지토리에는 올리지 않음)
- `src_512/` — 실루엣 영역만 잘라 512 로 줄인 텍스처 (8.7MB)

## 툴

- `felt_cutout_builder.py` — 이미지 한 장 → 얇은 컷아웃 메시
- `shrink_textures.py` — 여백 크롭 + 512 리사이즈
- `build_wall_flat.py` — 20종 일괄 빌드

Blender 에서:


### 동작 방식

1. 마젠타 크로마키 배경을 걷어 내 이진 마스크를 만든다
2. 픽셀 사이 틈(crack)을 따라가며 닫힌 폴리곤 루프를 뽑는다
   - 바깥 윤곽과 구멍이 부호 있는 면적으로 자동 구분된다 (무지개 아치, 울타리 틈)
3. RDP 로 계단 모양 경계를 매끈하게 줄인다
4. 구멍까지 포함해 삼각분할하고 Solidify 로 두께를 준다
5. 원본 이미지를 평면 투영 UV 로 입힌다

## 겪은 문제들

**흰 배경으로는 흰 펠트를 딸 수 없다.**
처음에는 흰 배경으로 뽑았는데 구름이 흰 펠트라 배경과 구분이 안 됐다.
배경을 마젠타 크로마키로 바꿔 해결했다. 프롬프트에 "물체는 절대 마젠타/핑크가 아니어야
한다" 를 넣어 두었다.

**마젠타 판정을 절대 밝기로 하면 안 된다.**
`b > 0.55` 로 자르니 `01_tree_apple` 의 배경(b=0.544)이 아슬아슬하게 빠져나가
이미지 전체가 전경이 되고 그냥 마젠타 사각형이 나왔다.
"빨강과 파랑이 초록보다 뚜렷하게 높다" 는 색상 관계로 바꿨다.
덤으로 전경 비율이 80% 를 넘으면 예외를 던지게 해 두어, 다시 사각형이 나오면 바로 걸린다.

**Solidify 의 use_even_offset 은 반드시 꺼야 한다.**
평평한 판의 테두리가 톱니처럼 잘게 꺾여 있으면 인접 면이 거의 마주 보게 되는데,
even offset 은 그 사이각으로 나누기 때문에 두께가 발산한다.
`01_tree_apple` 이 4mm 대신 **23m** 로 부풀어 올랐다.

**가장자리 배경색 테두리.**
배경과 물체 사이 안티에일리어싱 픽셀이 실루엣에 섞이면 테두리에 배경색이 남는다.
마스크를 2~3픽셀 안쪽으로 깎아(erode) 해결했다.
