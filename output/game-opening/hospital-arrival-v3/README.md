확정 오프닝 `opening-tv-cloud-fix-20260917-v1`은 수정하거나 재통합하지 않았다.

- 기존 병원 배경과 탐정 원화를 유지한다.
- 1920×1080, 60fps, 11.6초. 보행 한 주기 1.2초/72개 보간 프레임.
- 기존 네 가지 자세 사이를 관절 기준 메시로 보간한다. 72장을 새로 그린 것은 아니다.

- 거리 기반 축소, 오른쪽 문 회전, 문 안쪽으로 진입할 때 가림, 임시 발소리/문소리를 유지한다.
- 검수 후 추가 개선이 필요한 초안이며 완성된 수작업 캐릭터 애니메이션으로 표시하지 않는다.
