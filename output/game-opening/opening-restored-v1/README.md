뉴스·인터뷰·CRT 종료·암전은 `scene02-transition-v6/scene02-short-interview-transition-1080p.mp4`의 3–12.5초를 재사용했다.

탐정·하늘·타이틀은 남아 있는 기존 승인 그림과 체크 프레임을 사용했다.

## 재구성한 부분과 한계

로비→TV 확대 경로, 탐정→하늘 카메라 경로와 구름 이동은 다시 구현했다. 전화 자막은 남은 `timing.json`의 글자별 시간을 사용했다. 원본 영상과 바이트 단위로 동일하거나 카메라 움직임이 완전히 같다고 보장하지 않는다.

## 재실행

작업 루트의 번들 Node로 `restore-opening.cjs` 실행. FFmpeg와 @napi-rs/canvas 경로는 코드 상단에 있다.
중간 추출 프레임을 다시 만들 때는 scene02-transition-v6 원본에서 시작 0초/길이3초를 report-frames에, 시작3초/길이9.5초를 news-frames에 30fps PNG로 추출한다. 파일 번호는 000.png부터다.
입력 파일들은 기존 output/game-opening의 상대 폴더를 참조한다. 배포용 ZIP은 영상·음원·코드·기록의 보관용이며 모든 재렌더링 입력을 포함하는 프로젝트 전체 백업은 아니다.

실제 파일 크기와 SHA-256은 `manifest.json`에 기록한다. 원래 사라진 파일의 해시가 아니라 이번 복원본의 해시다.
