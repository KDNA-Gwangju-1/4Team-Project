# 병원 진입 — 보행 원화 검수

사용자 스케치 순서: 빈 병원 전경 → 가까운 탐정의 뒷모습 → 입구로 걸어감 → 문을 열고 들어감.
고정된 로우 앵글과 병원 소실점 유지. 출력 영상은 1920×1080.

## 보행 검수 기준

- 골반과 무릎, 발목이 연결된 다리 길이 유지. 프레임마다 머리·어깨 크기가 튀지 않아야 함.
- 지지하는 발과 앞으로 옮기는 발을 구분. 양발 접지 → 한발 지지 → 반대발 접지.
- 지지발 위로 체중이 이동하고 반대쪽 무릎이 굽혀져 발끝이 바닥을 통과함.
- 팔은 반대편 다리와 함께 전진. 코트 자락은 다리 움직임에 따라 제한적으로 반응.
- 후면에서 앞발은 더 먼 쪽으로 투영됨. 뒤꿈치를 들 때만 발바닥 일부가 보임.
- 실제 이동 합성 시 지지발의 화면 좌표를 확인하여 발 미끄러짐을 검수해야 함.
- 걷기 루프와 정지·문 손잡이 잡기·문 통과는 각각 별도 동작으로 취급.

참고: https://www.ouhsc.edu/bserdac/dthompso/web/gait/terms.htm
정상 보행의 지지기 약 60%, 유각기 약 40%는 참고 기준이며 생성된 그림의 정확성을 자동 보증하지 않음.

## 상태

이미지는 내장 image_gen으로 생성. 원화 및 보행 시트 검수 단계.
`detective-walk-study.png`는 생성된 8자세 원화이며 모든 자세를 통과시킨 최종 스프라이트가 아님.
`walk-review-draft.mp4`는 호환되는 네 자세(0, 6, 4, 2)를 선별한 6초, 1920×1080, 30fps 검수용 루프.
지지·유각의 중간 자세와 상체의 연속성은 추가 보완 대상. 월드 공간의 발 고정은 아직 검증하지 않음.
투명 픽셀 존재 확인 및 MP4 전체 디코딩 오류 없음. 실제 재생 감상으로 자연스러움이 확정되었다는 뜻은 아님.
영상 합성, 문 열기 동작 및 기존 영상과의 통합은 아직 완료하지 않음.
이 폴더의 새 작업은 기존 영상과 원화를 덮어쓰지 않음.
