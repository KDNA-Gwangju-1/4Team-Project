## 변경

기존에 승인된 네 가지 보행 자세를 유지하고 관절 기준점에 따른 메시 변형 및 정렬된 영상 혼합으로 한 주기를 36개 중간 프레임으로 구성했다. 36장을 전부 수작업으로 새로 그린 것은 아니다. 주기는 1.2초이며 30fps로 렌더링한다.
병원 접근 시 캐릭터 크기는 거리에 반비례하고 발 위치도 함께 변화한다. 문을 잡는 자세는 별도 생성하였다. 문은 슬라이드가 아닌 오른쪽 경첩을 중심으로 안쪽으로 회전한다.
원화 보완에 내장 image_gen 사용. 생성 프롬프트는 `prompts.json`에 보관.
소리는 직접 합성한 임시 발소리·손잡이·문소리이며 녹음된 폴리가 아니다.
