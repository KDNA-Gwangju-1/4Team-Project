# 병원 · 3D 전환 전 구간 검수 v1

- `hospital-before-3d-1080p.mp4`: 1920×1080, 60fps, 6.4초, AAC 효과음.
- 병원 전경 → 가까워지는 발소리 → 양쪽 전경에 신발·바지 끝단 진입 → 정지.
- 3.45초 / 4.05초 마지막 두 발 착지, 이후 2.35초 정지. 반사와 빛은 계속 움직임.
- 발은 두 개의 불투명 스프라이트를 독립 이동. 프레임 블렌딩, 광학 흐름 보간, 잔상 효과 없음.
- 배경 유리 영역만 약하게 이동하여 나무 반사 흔들림 표현. 건물 프레임 고정.
- 효과음은 로컬 합성 임시 발소리. 최종 녹음 폴리가 아님.
- 신발은 화면 양쪽에 걸치는 초근경 구도이며, 전신 보행이나 3D 리깅을 검증하는 영상이 아님.
- 문 열기, 3D 전환, 입장, 기존 오프닝 통합은 포함하지 않음.
- 기존 픽스 오프닝과 이전 병원 파일은 수정하지 않음.

## 재현

`render.cjs`는 함께 저장한 `hospital-background.png`, `shoe-cuff.png`를 읽음.
Node Canvas 및 프로젝트 내 FFmpeg 경로는 스크립트 상단에 명시.
원화만 built-in imagegen 사용. 영상·효과음·합성은 로컬 제작, Higgsfield 미사용.
생성 프롬프트는 `prompts.md` 참고.
