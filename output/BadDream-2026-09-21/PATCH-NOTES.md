# BadDream 에셋 패치노트 — 2026-09-21

이번 업데이트는 맵 디자인 시안과 크레파스 텍스트 에셋을 통합한 아트 패키지입니다. Unity 씬, 충돌체, 전투 로직에 적용한 업데이트는 아닙니다.

## 맵 시안

- 1스테이지: 전투 없는 일자형 로비.
- 2스테이지: 몹과 시스템을 소개하는 탐험 구간. 손전등·기억 수집은 배치 제안입니다.
- 2.5스테이지: 보스 전 연결 구간으로 선택 사용.
- 3스테이지: 보스 전장과 회피 공간.
- 동선 초안 → 에셋 배치 → 완성 시안을 비교하는 v3 이미지 12장 포함.
- 원경을 화면 전체에 늘리는 대신 작은 패턴으로 반복 배치했습니다.
- 액자·기억 그림을 크기, 기울기, 겹침이 다른 콜라주로 배치했습니다.
- 추가 시안 A(기억의 계단), B(찢어진 회랑), C(악몽의 분지)의 각 4개 구간, 총 12장 포함.
- 맵 이미지 총 24장과 브라우저에서 열 수 있는 단계별 비교 화면 2개 포함.

## 텍스트 및 그림 에셋

- ‘언니 싫어’의 최종 크레파스 액자 1종.
- ‘언니 싫어’ 텍스트 단독 1종과 그림 합성 5종: 가족 그림, 소녀 초상, 소녀 초상 액자, 트로피 소녀, 기울어진 가족 액자.
- 부정적 감정 문구 5종: ‘나만 미워해’, ‘저리 가’, ‘내 거야’, ‘혼자 있고 싶어’, ‘다 거짓말이야’.
- 최종 텍스트 관련 PNG 총 12종. 투명 알파 채널 확인.
- 글씨가 그림 전체를 덮도록 배치하고, 짙은 자주색과 여러 번 덧그은 거친 크레파스 질감을 사용했습니다.
- 초기 붉은 X·굵은 장식 버전, 작은 메모 버전 등 이전 시도는 원본 버전 폴더에 보존했습니다.

## 보스 모션 재수록

- 앞서 커밋한 Idle PNG·GIF와 사용자가 수정한 할퀴기 PNG·GIF·JSON을 통합본에 재수록했습니다.
- 이번 통합 과정에서 모션 원본을 다시 편집하지 않았습니다.

## 검증 및 적용 참고

- 통합 파일의 SHA-256, 이미지 크기, 알파 범위를 manifest.json에 기록했습니다.
- 맵 비교 화면의 선택 동작과 렌더링은 제작 과정에서 확인했습니다.
- 통합 ZIP의 무결성을 확인했습니다.
- 이미지 생성 도구로 제작한 텍스트 에셋의 프롬프트를 함께 보관했습니다.
- 실제 점프 거리, 충돌 판정, 몹 배치 난이도, 게임 내 최종 표시 크기에서의 글자 가독성은 Unity 적용 시 검증해야 합니다.
