# 챕터2 손전등 / 보스 반응 표시 수정

## 확인된 원인
- 정지 시 일반 idle 그림을 사용하고, 별도 손전등은 IsLightOn일 때만 표시해서 소지 중에도 빈손으로 보였다.
- 걷기는 손과 손전등이 포함된 그림, 정지/점프는 별도 크기와 위치의 손전등 그림을 사용했다.
- 대시는 일반 걷기 그림으로 돌아가 손전등이 사라졌다.
- 보스 진입 물음표는 기본 TextMesh 한 글자였다.

## 변경
- 손전등 소지 상태의 정지 그림을 새로 제작했다. 양발을 바닥에 놓고 기존 손전등과 팔의 형태를 유지했다.
- 정지/걷기/점프/대시 모두 손전등을 든 그림을 사용한다. 점프와 대시는 기존 holding 그림의 해당 자세를 사용한다.
- 별도 손전등 중복 렌더링을 끄고, 프레임별 렌즈 위치를 빛 시작점으로 사용한다. 좌우 반전과 컷신에도 적용한다.
- 정지 그림의 해상도에 비례한 PPU로 실제 표시 크기를 맞췄다. 정지/걷기 캔버스 월드 폭 모두 2.1880343.
- 보스 물음표는 보라색 테두리, 어두운 배경, 노란 픽셀 글자, 말풍선 꼬리로 구성했다. 기존 등장/퇴장 애니메이션을 유지한다.

## 검증
- Play Mode의 상태를 직접 설정하는 검사: 소지 2 × 방향 2 × 조명 2 × 동작 4 = 32개, 실패 0.
- 최종 새 정지 그림 로드, 중복 손전등 숨김, 렌즈와 빛 시작점 일치, 좌우 반전 확인.
- Stage1/Stage2/Stage3 모두 holding 그림 8장, 기존 PPU 234, HeldFlashlightVisual2D 연결 확인.
- Stage2 수정 전 화면과 보스 씬 수정 후 확대 화면을 직접 확인했다.
- 보스 배지는 실제 보스 씬에서 반응 코루틴을 직접 실행하고 표시 크기를 고정하여 캡처했다. 전체 컷신 타이밍 통과 검사는 아니다.
- 최종 컴파일 및 Console error 0, 변경한 세 스크립트 diff whitespace 검사 통과.
- Play Mode 종료, BadDream_stage2 씬으로 복귀. 테스트용 값과 카메라는 저장하지 않았다.

## 범위 / 남은 시각적 제약
- 이번 검증은 제보한 손전등과 보스 진입 반응에 집중했다. 챕터 전체 플레이 완료 또는 모든 버그 해소를 의미하지 않는다.
- 캐릭터는 기존 프레임 기반 애니메이션이다. 빛은 마우스 방향으로 조준하지만 팔 자체가 모든 각도로 회전하는 전용 조준 애니메이션은 추가하지 않았다.
