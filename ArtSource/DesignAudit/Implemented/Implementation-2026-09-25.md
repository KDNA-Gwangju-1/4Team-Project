# 디자인 우선순위 2~6 적용

1번 엔딩 이후 콘텐츠는 사용자 요청에 따라 보류. Stage3EndingCutscene은 이번 작업에서 수정하지 않았다.

## 2. 챕터2 플레이 요소 구분
- 직전 작업의 배경 RGB 20% 감소를 유지.
- 세 씬의 반복 낙서/접힌 기억 장식 중 18개를 비활성화. 대표 액자는 유지.
- Stage2 15개, Stage3 3개 점프 발판에 실제 충돌면을 따라가는 가는 밝은 착지선을 연결.
- 숨겨진 발판은 원본 SpriteRenderer의 표시/알파에 따라 선도 숨김. 실제 실행에서 숨겨진 발판 2개의 선 비노출 확인.
- 아군 금빛 탄환과 적군 붉은 탄환, 적의 기존 손전등 실루엣 규칙은 보존.
- Stage1은 평지 구조이므로 점프 발판 표시를 억지로 추가하지 않음.

## 3. 챕터1 보스 약점 연출
- 전용 봉제 코어, 열린 고리와 바느질 무늬, 맥동, 명중 섬광/방사형 조각, 닫힘 축소를 추가.
- 실제 보스 충돌 영역의 카메라 쪽 면에 표시. 별도 피격 판정은 만들지 않음.
- 본체를 어두운 보라색으로 칠하는 임시 표시 대신 전용 표시 사용.
- 문구에 '보스 본체를 정화하세요'를 표시하여 작은 코어만 맞혀야 하는 것으로 오해하지 않도록 함.
- 직접 상태 전환 및 충돌 콜백을 사용한 런타임 검사: 3회 정화 후 노출, 노출 구간당 1회 인정, 6회 성공 시 종료 확인.
- 보스 모델/충돌체를 켠 검증 화면에서 약점 위치 확인. 전체 아레나 전투를 처음부터 끝까지 수동 플레이한 검증은 아님.

## 4. 일시정지 확인창
- 예/아니요 200×62 버튼을 같은 줄에 배치. 360 높이 패널 안에 하단 여백 확보.
- 좌우 키보드 이동 명시 연결.
- 실제 화면 캡처, 두 버튼의 패널 내부 배치, Submit 이벤트로 '아니요' → 메인 일시정지 페이지, Resume 동작 확인.

## 5. 챕터2 보스 체력바
- 공용 악몽 카드, 이름/페이즈/체력 수치, 아래쪽 게이지로 정리.
- 1단계/전환 중/2단계 문구와 채움 색상 분리. 기존 피격 잔상 유지.
- 보스 체력 0 또는 제거 시 숨김.
- 런타임 상태 주입으로 1단계 16/16, 2단계 3/16과 fill=0.1875, ghost=1 검증.
- 검증 캡처의 보스/대사/아레나 상태는 HUD 검증을 위해 정지·직접 설정한 상태이며 전체 페이즈 컷신의 회귀 검증은 아님.

## 6. 로딩 화면
- 밝은 낮 병원 그림 제작. 기존 밤 원본 유지.
- 병원 진입 및 병실 이동 오버레이에 낮 그림 연결. 연결 위치 질문에 응답이 없어 명시한 기본안으로 진행.
- 병원/밝은 꿈/악몽/메인 메뉴 목적지별 안내 적용. 호출자가 전달한 배경은 우선 유지.
- Loading 씬 최소 표시 9초 → 2.5초. 실제 로딩이 더 길면 완료까지 기다림.
- 실제 Loading → HospitalRoom 성공, 측정 2.831초. HospitalRoom의 오버레이도 낮 그림 로드 확인.
- 실제 Loading → MainMenu 이동 확인.
- 팁 배치와 넓은 화면의 그림 비율 유지 확인.

## 최종 확인과 범위
- Unity 컴파일 성공, 마지막 Console Error 0.
- 관련 스크립트 diff 공백 검사 통과, 새 에셋/스크립트의 Unity meta 생성 확인.
- Play Mode 종료 후 BadDream_stage2 편집 상태로 복귀. 테스트 카메라/전투 상태 저장하지 않음.
- 현재 넓은 Game View에서 시각 검증. 별도 1280×720 기기/빌드 검사와 전체 챕터 통과 플레이는 이번 검증에 포함되지 않음.
