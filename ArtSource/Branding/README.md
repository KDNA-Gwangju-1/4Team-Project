# RE:DREAM / 4TEAM 영상 브랜딩

사용자 지정 개발팀 명칭: **4TEAM**.

4TEAM은 네 개의 파스텔 사각형과 텍스트로 만든 간단한 영상용 워드마크다. 게임 타이틀은 기존 시네마틱의 RE:DREAM 표기를 사용한다.

MadeWithUnity-official.png는 Unity 공식 사이트에서 제공되는 원본 배지를 변경하지 않고 사용했다.

- 원본: https://cdn.sanity.io/images/fuvbjjlp/production/ed8ae4aba799bd64a04b6dee9e9f4eaee5735bc6-415x100.png
- 사용 지침: https://unity.com/legal/branding-trademarks
- 배지 화면에 Unity와 제휴/후원 관계가 없다는 문구와 상표 고지를 포함했다.

이 작업은 시네마틱 앞의 로고 카드다. 게임 실행 시 Unity Player splash 설정이나 메인 메뉴 진입 흐름은 변경하지 않았다.
