# RE:DREAM 챕터별 사운드 준비 목록

작성일: 2026-09-26

## 범위와 판단 기준

Unity MCP 없이 로컬 에셋, 저장된 게임 화면, 씬 텍스트, 사운드 코드를 확인해 작성한 제작 제안이다. 이번 작업에서 게임을 실행하거나 기존 오디오를 청음하지 않았다. 기존 파일이 있다는 사실과 최종 소리 품질은 구분한다. 게임 에셋과 코드는 수정하지 않았다.

핵심 방향: **포근한 봉제 정원 → 기억이 뒤틀린 종이·크레용 악몽 → 현실로 돌아오는 안도감.** 같은 짧은 멜로디를 정원에서는 맑게, 악몽에서는 끊기고 흔들리게, 엔딩에서는 편안하게 들려주는 구성을 제안한다.

README와 이전 사운드 문서에는 보스의 챕터/형태 설명이 일부 엇갈린다. 이 목록은 저장된 정원 화면의 봉제 유니콘, 챕터 2 소녀 보스 화면과 검은 발톱 스프라이트를 기준으로 구분했다. 과거 BOSS_DESIGN.md의 미구현 표기를 현재 상태로 단정하지 않는다.

표의 ‘기존’은 해당 파일 확인, ‘보강’은 기존 공용음 또는 관련 소리에 재질/캐릭터별 변형 추가, ‘신규’는 이번에 제안하는 전용 사운드다. 신규 표기는 모든 파일의 음향 내용을 분석해 중복을 배제했다는 뜻은 아니다.

## 0. 현실 / 병실 / 메뉴

정돈된 병실, 커튼, 의료 패널, 문과 긴 복도에 맞춰 작고 현실적인 소리로 시작한다. 병원 소음은 꿈과 대비되는 현실의 기준점이다.

| 분류 | 준비할 소리 | 질감·사용 시점 | 준비 상태 |
|---|---|---|---|
| BGM | 메뉴 / 병실 음악 | 절제된 피아노와 긴 여운, 대사를 가리지 않는 밀도 | 기존 WhispersOfTheNight / WhispersOfNight 검토 |
| 환경 | 병실 룸톤 | 낮은 환기음, 조용한 전기 장치의 진동, 멀리 있는 생활 소음 | AmbHospital 보강 |
| 이동 | 타일 발소리 / 착지 | 짧고 단단한 밑창, 복도 잔향; 발소리 4~6변형 | StepTile / Land 보강 |
| 소품 | 문 손잡이 / 열기 / 닫기 | 손잡이 클릭과 경첩, 문이 닫히는 둔탁한 끝소리 | Door 세분화 |
| 소품 | 침구 / 옷 스침 | 환자에 가까이 다가가거나 접촉하는 순간 | 신규, 연출 동작에 맞출 것 |
| 전환 | 꿈 진입 | 실내 소리가 멀어짐 → 짧은 흡입음 → 맑은 잔향 | Portal 보강 |

## 1. 챕터 1 — 밝은 꿈 / 봉제 정원

확인한 시각 요소: 바느질 선이 보이는 나무와 잔디, 꽃, 온실, 산책로, 다리, 그네의 리본, 사진첩, 나무 각인, 편지, 장난감 정화총, 봉제 유니콘, 보라색 균열과 손.

음악은 오르골·첼레스타·부드러운 피아노·피치카토를 중심으로 제안한다. 몬스터와 보스도 천·솜·단추의 재질을 살리고, 균열부터 저음과 뒤집힌 잔향을 추가한다.

## 2. 챕터 2 — 어두운 꿈 / 기억·낙서 세계

확인한 시각 요소: 어두운 보라색 공간, 떠 있는 발판, 가족 그림·액자·부정적인 낙서, 손전등, 봉제 토끼·종이접기 새·야간등 에셋, 인형을 안은 소녀 보스, 그림자와 긴 발톱.

종이·크레용 마찰, 끊기는 오르골, 긴 공간 잔향을 중심으로 제안한다. 적 공격과 이동 판단에 필요한 소리는 짧고 또렷하게 유지한다. Stage1·2는 같은 세계이므로 기본 음악을 공유하고 Stage2에 긴장 레이어를 추가해도 된다.

| 구간 | 준비할 소리 | 질감·사용 시점 | 준비 상태 / 우선도 |
|---|---|---|---|
| Stage1 BGM | 악몽 탐색 | 정원 멜로디의 일부가 빠지거나 조율이 흔들리는 구성 | BGM_Stage1_2 검토 / 높음 |
| Stage1 환경 | 빈 기억 공간 | 낮은 공기 진동, 드문 종이 스침, 멀리서 한 번씩 나는 액자 삐걱임 | 신규 / 높음 |
| Stage1 소품 | 손전등 획득·켜기·끄기 | 획득 확인음, 물리 스위치 클릭 | Pickup / Flashlight_On / Off 활용 |
| Stage1 피드백 | 빛으로 적·약점 발견 | 어둠이 벗겨지는 짧은 소리; 대상을 계속 비춘다고 반복하지 않음 | Weakpoint 응용 / 높음 |
| Stage1 소품 | 쪽지 펼침·닫힘 / 문 / 잠긴 문 | 종이 바스락, 문 경첩, 잠금장치의 짧은 걸림 | Paper / Door 보강 |

| 공통 무기 | 빛 발사 / 명중 / 정화 | 밝고 짧은 발사음, 맞음과 정화 완료를 구별 | LightShot_1~3 / Purify 활용 |

| 종이접기 새 | 발견 / 날갯짓 / 돌진 | 종이를 튕기는 질감과 날카로운 바람 | Crow_Notice 기존, 이동·돌진 보강 / 중간 |

| Stage3 촉수 | 출현 / 공격 예고 / 타격 | 종이·그림자가 늘어나는 소리 → 짧은 공기 절단 | Tentacle_Rise / Tentacle_Hit_1~3 보강 |
| Stage3 변신 | 1→2페이즈 전환 | 오르골이 멈춤 → 종이 찢김·역재생 흡입 → 저음 충격 | 신규 / 높음 |
| Stage3 2페이즈 | 보스 음악 | 같은 동기의 낮은 음역, 강한 리듬, 불협화음 증가 | BGM_Boss_Phase2 검토 |
| Stage3 발톱 | 휘두르기 예고 / 스윙 / 충돌 | 길게 긁는 크레용, 날카로운 바람, 바닥의 둔탁한 충격 | 전용 신규 / 높음 |

적 종류별 소리는 에셋 테마에 따른 제안이다. 스테이지별 실제 배치 개체와 재생 조건은 연결할 때 확인한다. 장식용 가족 그림마다 별도 소리를 붙이기보다 구간 환경음으로 묶는다.

## 우선 제작 묶음

1. **챕터 1 음악**: 탐색 루프 / 전투 레이어 / 유니콘 보스 루프. 현재 오디오 파일 목록에서 전용 음악을 찾지 못했다.
2. **단서 독백 5개**: 기존 로더의 파일명에 맞춰 복구 또는 제작.
3. **핵심 위험 신호**: 유니콘 돌진·내려찍기 예고 구분, 챕터 2 발톱 예고, 약점 노출·파괴 구분.
4. **챕터 전환 연출**: 균열·손 잡기·끌기, 챕터 2 변신, 악몽 소멸.
5. **챕터 2 환경과 엔딩 음악**: 기존 Stage1·2 / 보스 음악은 먼저 청음하고 보강 여부 결정.
6. **반복 Foley 품질**: 발소리 재질·변형, 종이·천, 몬스터별 개성.

## 제작·연결 메모

- 제안 길이: 탐색 음악 60~120초 루프, 전투·보스 45~90초 루프, 환경 30~60초 루프. 단발 효과는 보통 0.1~2초, 연출음은 장면 길이에 맞춘다. 이는 현행 파일 규격이 아닌 제작 시작점이다.
- 발소리 4~6변형, 자주 반복되는 발사·명중 3변형을 우선 준비한다.
- 납품 원본은 WAV 48kHz/24-bit 권장. 위치가 있는 효과·보이스는 mono, 음악·넓은 환경은 stereo. 루프는 끝과 시작을 이어 청취해 확인한다.
- 대사 중에는 음악과 환경음을 낮추고, 위험 예고는 음악보다 잘 들리게 한다. 정적도 연출 재료로 사용한다.
- 현재 GameSfx의 환경음 선택은 병실/정원만 포함한다. 챕터 2 환경 루프를 추가하려면 별도 연결이 필요하다.
- 현재 공용 Warning은 여러 경고 용도로 쓰인다. 타이머·돌진·내려찍기를 별도 큐로 나누려면 파일뿐 아니라 호출부도 분리해야 한다.
- BossMusic2D는 페이즈 0에서 전투 음악을 내린다. 보스 등장·변신·엔딩 음악/연출음은 해당 컷신 타이밍에 별도로 연결해야 한다.
- 여러 적이나 탄막에서 같은 소리가 동시에 쌓이지 않도록 재생 수와 간격을 제한한다. 현재 BossSounds2D에는 연속 발사 묶음 처리가 있다.
