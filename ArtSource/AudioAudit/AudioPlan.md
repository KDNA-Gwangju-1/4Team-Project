# RE:DREAM 사운드 점검 · 2026-09-25

## 조사 범위와 결과

빌드에 등록된 8개 씬의 AudioSource, 직렬화된 AudioClip 참조, 사용 중인 스크립트와 재생 경로를 확인했다. 전체 게임을 사람처럼 처음부터 끝까지 플레이하거나 청음한 검수는 아니다. 병원·챕터1·챕터2는 아래 이벤트를 Play Mode에서 별도로 실행했다.

| 씬 | 기존 연결 | 이번 보완 / 남은 작업 |
|---|---|---|
| MainMenu | WhispersOfTheNight 리소스에서 음악 로드. Inspector의 빈 musicClip은 누락이 아님 | 버튼 선택·클릭음 |
| Loading | 전환 화면 | 출입문·포탈 효과음이 전환 중 마저 재생되도록 처리 |

HiddenFlyer의 noticeClip, Crow의 moveClip은 선택적 필드이며 사용하지 않는다는 이유만으로 오류로 처리하지 않았다. 원본 조사 내역은 SceneInventory.tsv와 SceneBehaviours.txt에 있다.

## Unity에서 제작·연결한 소리

`Assets/Editor/ProceduralAudioBuilder.cs`의 Tools → Audio → Build Authored Game Cues로 재생성할 수 있다. 48kHz/16-bit/mono WAV 27개를 만들었다. 26개는 게임 피드백·환경음이며 Brand 1개는 영상 로고용이다. 자연 녹음이 아닌 합성음이므로 실제 재질감의 최종 품질 검수는 별도로 필요하다.

| 목적 | 리소스 이름 |
|---|---|
| UI | UiHover, UiClick, UiBack |
| 탐색 | Door, Pickup, Clue, Paper, Portal |
| 전투 | Shot, Purify, WrongHit, Hurt, Weakpoint, Warning, Slam |
| 승패 | Victory, Defeat |
| 균열·손 | RiftOpen, RiftGrab, RiftClose |
| 이동 | StepTile, StepGrass, Jump, Land |
| 환경·영상 | AmbHospital, AmbGarden, Brand |

GameSfx는 12개의 재사용 AudioSource와 환경음 1개를 사용한다. 기존 BGM/2D 효과음 시스템은 그대로 둔다. 기존 마스터 볼륨에 따르며, 일시정지 중 월드 효과음은 차단하고 UI 효과음은 허용한다. 같은 효과의 연속 재생을 짧게 제한한다. 씬 전환 때 이전 효과음은 정리하되 출입문·포탈 소리는 끝까지 재생한다. 별도 패키지는 추가하지 않았다.

권장 납품: 편집 원본 WAV 48kHz/24-bit, 단발 효과·보이스 mono, 환경·음악 stereo. 루프 파일은 시작과 끝이 자연스럽게 이어지게 하고 음악은 가능하면 멜로디/리듬/환경 레이어도 분리한다. 이는 제작용 권장 규격이며 Unity 배포 압축은 용도별로 별도 조정한다.

## 검증과 한계

- Unity 컴파일/Console 오류 확인.
- 챕터1: 실제 획득, 정화총 발사, 피격, 인형 정화에 따른 약점 노출 이벤트로 소리 재생 확인.
- 병원: 출입문, 환경음/BGM 동시 재생, 이동에 따른 발소리 2회 확인.
- 일시정지: 월드 소리 차단, UI 소리 허용. AudioListener 볼륨 0 유지 확인. 옵션 화면 슬라이더를 직접 조작한 검증은 아님.
- 챕터2: 실제 쪽지 열기/닫기와 BGM 동시 재생 확인. 런타임 검증용 DeathRetryUI2D를 만들어 Show를 두 번 호출했을 때 패배음은 1회만 발생함을 확인. 실제 죽음부터 재시도까지의 전체 플레이 검증은 아님.
- 씬 전환 후 GameSfx 1개 유지 확인. 검사 중의 위치 변경/검증 객체는 Play Mode 종료로 폐기.
- 전체 스테이지 완주, 모든 카메라 거리에서의 음량 청취, 헤드폰/스피커별 믹싱과 장시간 플레이는 남은 QA다.

SfxPreview.wav는 UI → 문 → 획득 → 단서 → 종이 → 발사 → 정화 → 피격 → 약점 → 균열 열림/잡기/닫힘 → 승리 → 패배 순의 미리듣기다. 런타임보다 큰 원본 음량이므로 실제 게임 믹스와는 다르다.

## 원격 작업 통합

최초 검증 후 원격의 6c8806c까지 추가된 13개 커밋(체크포인트, 2D 타임어택, 조작 안내 등)을 보존하여 통합했다. 위 SceneInventory/SceneBehaviours 및 런타임 기록은 통합 전 조사 스냅샷이다. 통합 코드에서는 체크포인트 복구가 DebugCollectAll/DebugGrant를 사용하여 획득·단서 효과음을 잘못 재생하지 않음을 확인했다. 새 2D 타이머의 마지막 10초 청각 알림은 추가 보완 대상으로 남아 있으며, 체크포인트와 타이머 변경 전체에 대한 플레이 검증을 완료한 것은 아니다.
