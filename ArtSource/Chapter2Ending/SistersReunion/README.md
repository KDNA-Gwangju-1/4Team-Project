# 자매 재회 — 눈뜨기 컷 다음 장면

`sisters-reunion-v1.mp4`: 10.5초, 1920×1080, 60fps, 무음.

동생이 깨어난 클로즈업 다음에 들어갈 **원화와 컷 편집 중심의 시네마틱**이다. 두 사람이 일어나 앉고 팔을 벌려 포옹하기까지를 연속적으로 그린 전신 애니메이션은 아니다. 자세 사이를 모핑하지 않고 컷으로 생략하여 연결한다.

## 편집 순서

| 구간 | 화면 |
|---|---|
| 0.00–3.00초 | 두 사람이 각자 침대에 앉아 눈을 마주치는 투샷. 아주 느린 접근. |
| 3.00–3.85초 | 동생이 언니 손으로 손을 뻗은 클로즈업. |
| 3.85–5.80초 | 더 가까운 손 접촉 컷. 동생 손이 언니 손 위에 놓여 있다. |
| 5.80–10.50초 | 침대 위에서 껴안은 두 사람. 잠시 머무르며 조금 물러나는 카메라. |

기존 포옹 원화와 눈뜨기 컷을 참조해 갈색 단발, 연한 청회색 환자복, 왼쪽 햇빛과 병실의 두 침대를 맞췄다. 언니는 화면 왼쪽, 동생은 오른쪽이다. 캐릭터가 침대에서 내려오거나 걸어가는 장면은 없다.

`Ending-sequence-preview-v1.mp4`는 **눈뜨기 9초 → 재회 10.5초 → 빈 복도 13.4초**, 총 32.9초를 연결한 검토 영상이다. 개별 원본 영상은 수정하지 않았다.

## 제작 및 검수

원화 4장은 imagegen 스킬의 내장 `image_gen`으로 만들었다. 프롬프트 사양과 참조는 `Prompts.md`에 기록한다. `render.py`가 고정 원화에 균일한 화면 확대·축소와 컷 편집을 적용한다. 캐릭터·배경의 국소 변형, 자세 간 크로스페이드, 손 보간 및 프레임 깜빡임은 최종본에 사용하지 않는다.

초기 손 보간에서 두 손이 겹치는 잔상이 발견되어 제거하고 접촉 삽입 컷으로 대체했다. 최종 `Storyboard-v1.jpg`의 대표 프레임을 확인하고 개별 영상 630프레임 및 연결본 1,974프레임 전체를 디코드해 1080p/60fps를 확인했다. `Validation-v1.json` 참조. 정지 프레임·파일 검사가 실시간 재생 인상의 승인을 대신하지 않는다.

게임 적용: `Assets/StreamingAssets/Cinematics/EndingAndHospital.mp4`에 연결본을 복사했다. 챕터2 보스 엔딩의 기존 대화와 흰색 페이드 뒤에 재생하며, 기존 BGM_Ending을 이어서 사용한다. 영상 종료 또는 ESC 2초 유지 시 기존 로딩 화면을 거쳐 메인 메뉴로 돌아간다. 영상 재생 실패도 메뉴로 진행한다. 영상 자체에는 음성·효과음이 없다.
