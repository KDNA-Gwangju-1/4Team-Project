# 동생이 눈을 뜨는 병실 클로즈업

검토 영상: `sister-awakening-v1.mp4` — 9초, 1920×1080, 60fps, 무음.

엔딩 순서는 **동생의 오른쪽 침대 클로즈업 → 자매 포옹 → 빈 병원 복도와 창밖 바람**을 기준으로 한다. 이번 결과는 첫 번째 컷이다. 기존 포옹 작업은 `output/ending-v1/pixel/embrace-in-bed-v2.png`의 정지 원화였으며, 이 컷 제작에서 포옹 애니메이션을 새로 완성하거나 게임 엔딩 전체에 연결한 것은 아니다.

## 연출

- 0.00–2.05초: 흰 베개 위에 누운 동생의 감은 눈을 보여준다.
- 2.05–2.52초: 작게 반응하는 눈꺼풀. 다시 잠시 닫힌다.
- 2.85–4.65초: 눈을 천천히 뜬다. 양쪽 눈의 시작에 0.045초 차이를 둔다.
- 4.65–6.30초: 열린 눈으로 잠시 주변을 받아들이는 정지 자세.
- 6.30–6.78초: 한 번 깜빡이고 다시 뜬다.
- 6.78–9.00초: 열린 눈을 유지해 다음 컷으로 편집할 여유를 둔다.

참조는 기존 병원 장면과 자매 포옹 원화다. 오른쪽 동생의 갈색 단발, 연한 청회색 환자복, 낮은 대비의 흰 침구, 화면 왼쪽의 따뜻한 빛을 이어갔다. 두 참조는 `assets/`에 보존했다. 병실을 그대로 캡처한 것이 아니라 해당 공간과 외형을 참고해 새로 생성한 클로즈업이다.

## 제작 및 검수

원화는 imagegen 스킬의 **내장 image_gen**으로 생성했다. 닫힘·반쯤 열림·열림 3개 원화를 사용하고, 눈 주변의 작은 두 영역에만 국소 광학 흐름 보간을 적용했다. 60fps 출력 540프레임이 각각 새로 그린 원화 540장은 아니다. 머리, 얼굴 윤곽, 코, 입, 침구 및 배경은 첫 원화로 고정했다. 기존 복도 영상의 프레임 끊기·깜빡임 연출은 사용하지 않는다.

`render.py`가 540프레임 전체에서 눈 영역 밖의 픽셀 변경이 0인지 검사하고, 출력 전체 디코드·해상도·프레임 수를 확인한다. `Validation-v1.json`에 결과와 타이밍을 기록한다. `Eye-motion-review-v1.jpg`와 `Storyboard-v1.jpg`로 주요 시점의 눈·전체 화면을 확인했다. 보간된 눈꺼풀에는 일부 질감 혼합이 생길 수 있으며 수치 검사가 재생 인상의 최종 승인을 대신하지 않는다.

Unity에는 아직 연결하지 않은 검토용 컷이다. 대사·음향·음악은 포함하지 않았다. 원화와 최종 프롬프트 사양은 `Prompts.md`에 기록한다.
