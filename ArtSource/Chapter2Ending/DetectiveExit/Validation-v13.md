# v13: 자세와 위치를 함께 끊고 이동 사이에 블러

v12는 자세만 줄이고 캐릭터 위치를 매 출력 프레임 갱신했다. 사용자가 요청한 위치의 간헐적 이동을 반영하지 못했다.

v13은 캐릭터의 자세·위치·원근 크기를 모두 초당 6번 샘플링한다. 60fps 출력의 각 10프레임 중 처음 8프레임은 같은 화면을 유지하고, 나머지 2프레임은 이전 위치에서 다음 위치까지 이동하는 짧은 노출을 표시한다. 각 노출은 이동 경로의 9개 샘플을 평균해 방향성 블러를 만든다. 다리의 국소적인 흐림이 아니라 캐릭터 전체가 다음 위치로 넘어가는 흐림이다.

배경과 카메라는 고정했다. 노출 샘플 사이에서도 문과 배경은 동일하게 유지한다. 문 동작도 6Hz의 시작 상태를 사용한다. 페이드 인·아웃만 출력 프레임마다 갱신한다. 이 구성은 60fps의 부드러운 위치 보간과 의도적으로 다르다.

- `detective-exit-stepped-v13.mp4`: 전체 13.4초, 1080p/60fps 컨테이너, 캐릭터 갱신 6Hz, 무음.
- `Comparison-v12-v13.mp4`: 왼쪽 v12의 연속 위치 이동, 오른쪽 v13의 위치 유지·이동 블러.
- `Storyboard-v13.jpg`: 같은 위치 유지 구간과 블러 전환을 포함한 정지 프레임.
- 제작: `render_v13.py`. 검사: `validate_v13.py`, 결과 `Validation-v13.json`.

위치 유지 프레임의 실제 이미지 동일성, 전환 프레임의 이미지 변화, 전환 중 배경 영역의 동일성 및 영상 전체 디코드를 검사한다. 이는 재생 시 자연스러움에 대한 사용자 승인을 의미하지 않는다. 기존 원화의 동작 한계는 유지된다. Unity에는 아직 연결하지 않은 검토본이다.
