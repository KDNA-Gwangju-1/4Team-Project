# v9 — 탐정 퇴장 동작 연결 수정

## 확인한 작업 내역

- 로컬 초기 블로킹 기록: 8개 보행 자세와 4개 문 동작, 카메라 원근과 문 경첩 투영. 접촉/발 미끄러짐을 미완료로 기록했음.
- v5–v7 비교 파일과 v7 검증 기록: v7은 머리 기준점과 키를 정렬해 위치 떨림을 줄였으나, 기록의 수치는 기준점 안정성 지표이며 실제 신체 리깅 검증이 아님.
- v8 소스: 주 구간은 60/7fps, 측면은 20/3fps로 렌더. 캐릭터·배경을 이미 합성한 영역에 minterpolate와 3프레임 시간 평균을 적용. 마지막에 두 렌더를 0.15초 디졸브로 연결.
- 문 동작 원화 4/5번은 건너뛰고 있었음. 계산된 foot 값은 place에서 사용하지 않으므로 발 접지 제약으로 작동하지 않았음.
- 이동은 감속하지만 phase는 시간에 비례해 계속 진행했음. 퇴장은 문틀로 가려지기 전에도 11.4초에서 visible=false로 끊었음.
- 원화, 알파, 보행·문 열기·방향 전환 포즈, 배경, 필터와 재현 스크립트를 직접 확인했음.

## 변경

1. 하나의 시간축에서 744프레임을 직접 렌더한다. 두 영상의 연결 디졸브와 화면 영역 전체에 대한 보간·시간 평균을 제거했다.
2. 캐릭터 원화를 같은 머리 중심·키·바닥 기준으로 등록한 뒤 캐릭터 RGBA에만 양방향 움직임 보간을 적용한다. 배경과 문틀이 신체 움직임에 끌려 일그러지는 경로를 없앴다.
3. 출발 준비, 가속, 감속을 분리하고 접근 보행의 자세 진행을 이동 거리에 연결했다. 멈추기 직전 서 있는 자세로 전환한다.
4. 문 동작 0→1→2→3→4→5→6→7을 모두 사용한다. 미는 발동작과 작은 전진을 맞추고, 손이 닿는 동안 손끝과 회전 손잡이의 가로 위치를 보정한다. 손 놓기 때 보정은 부드럽게 해제된다.
5. 방향 전환 시간을 0.45초에서 0.84초로 늘렸다. 앞쪽 발을 크게 내딛는 a9→a10 구간은 자동 보간에서 반투명 다리가 겹쳐 보여, 손목·무릎·발목·발끝의 대응점을 지정한 2D 곡면 변형으로 대체했다.
6. 측면 걸음에서 거의 같은 접촉 자세를 연속 사용하지 않게 조정했다. 이동 가속에 따라 보행 주기도 따라간다.
7. 시간에 따른 강제 소멸을 제거했다. 실제 화면 위치와 문틀의 가림 처리로 퇴장한다. 빈 복도 여운 뒤 마지막 0.75초에 페이드아웃한다.
8. 720p 합성 중간 단계를 제거하고 원본 배경 해상도 1672×941에서 합성 후 1920×1080으로 출력한다.

## 검수

- 12.4초, 60fps, 1920×1080, 744프레임, 무음. 전체 영상 디코딩 검사는 Decode-v9.txt에 기록한다.
- 접근·정지·문 열기·문턱 통과·회전·퇴장 총 16시점과 회전/손 접촉 구간의 확대 연속 프레임을 확인했다.
- 최초 v9 검수에서 발견한 a9→a10 다리 겹침을 다시 수정하고 최종 렌더했다.
- Comparison-v8-v9.mp4에서 같은 시간의 확대 장면을 나란히 비교할 수 있다. 연출 시간이 변경되어 특정 자세가 나타나는 시점은 두 버전이 다르다.
- Validation-v9-motion.json은 시간축/포즈/위치 표본 기록이다. 실제 사람처럼 자연스럽다는 객관적 점수로 해석하면 안 된다.

## 남은 한계

기존 2D 원화의 중간 자세를 계산한 버전이다. 실제 3D 뼈대, 관절 제한, 발의 월드 좌표 고정이나 손의 3D 접촉을 시뮬레이션하지 않는다. 원화 간 코트·신발 실루엣 차이와 일부 미끄러짐·국소 잔상은 남을 수 있다. 확대 프레임 검수와 디코딩 검사를 수행했으며, 사람이 실시간으로 전편을 감상한 검수는 아니다. 완전한 발 접지와 캐릭터 연기는 추가 중간 원화 또는 별도 리깅 제작이 필요하다. 기존 무음과 Unity 미연결 상태를 유지했다.
