# v14: 위치 전환과 동기화된 화면 깜빡임

사용자가 v13은 단순한 프레임 저하처럼 보인다고 지적해, 위치 전환이 연출로 보이도록 전체 화면의 노출 변화를 추가했다.

- 입력: `detective-exit-stepped-v13.mp4`. 기존 자세·위치 유지와 이동 블러를 그대로 사용한다.
- 각 10프레임 중 7, 8, 9번째 슬롯의 밝기를 각각 91%, 78%, 90%로 낮춘 뒤 다음 위치에서 100%로 복귀한다. 기존 이동 블러는 8, 9번째 슬롯이므로 가장 어두운 순간과 이동 노출이 겹친다.
- 접근·문 통과·퇴장 보행에만 적용하고, 구간 시작과 끝에서는 강도를 점진적으로 조정한다. 대기·문 열기·방향 전환 구간에는 주기적 노출 효과를 넣지 않는다.
- 검정 프레임 삽입이나 밝은 섬광, 공간 변형은 사용하지 않는다. v13의 배경 형태를 유지하며 전체 화면 밝기만 변화한다.
- 전체 영상과 좌우 비교는 13.4초, 60fps, 무음이다. 원본 v13은 보존한다.

`render_v14.py`는 렌더 후 두 출력의 전체 디코드·프레임 수·해상도를 검증해 `Validation-v14.json`에 기록한다. `Storyboard-v14.jpg`는 선명한 유지 → 어두워짐 → 이동 블러 → 밝기 복귀 구간의 6프레임이다. 정지 프레임과 파일 검증은 재생 인상의 자연스러움에 대한 사용자 승인을 대체하지 않는다. Unity에는 아직 연결하지 않았다.
