# 4Team-Project

NC-AI 4팀이 Unity로 제작한 3D/2D 혼합 어드벤처 게임 프로젝트입니다.
꿈속을 탐색하며 단서를 모으고, 손전등으로 위협을 드러내고, 보스를 물리치는 것이 핵심 루프입니다.

## 팀원

| 역할 | 이름 |
|---|---|
| 팀장 | 이원주 |
| 팀원 | 김명주, 김슬빈, 임현규, 윤남기, 주서연 |

역할 분담 및 진행 상황은 별도 Notion 페이지에 정리되어 있습니다.

## 기술 스택

- **엔진**: Unity 6 (6000.3.21f1)
- **언어**: C#
- **입력**: 챕터별로 방식이 다릅니다 — 3D 파트(BrightDream)는 레거시 Input 매니저, 2D 파트(BadDream)는 Unity Input System을 사용합니다.
- **AI/내비게이션**: NavMesh (보스 추적 등)
- **UI**: uGUI 기반, 챕터별 스킨(`ChapterDialogueSkin`, `ChapterHudStyle` 등)을 코드로 입혀 통일된 룩을 유지합니다.

## 게임 소개

주인공은 병실(현실)에서 잠든 아이의 꿈속으로 들어갑니다. 꿈은 두 갈래로 이어집니다.

- **밝은 꿈 (챕터 1, 3D)**: 정원을 돌아다니며 단서 4개를 모으고 정화총을 얻어, 정화총으로 몬스터를 처치하고 보스(촉수형 괴물)를 무찌릅니다.
- **어두운 꿈 (챕터 2, 2D)**: 손전등으로 어둠 속 위협을 비춰 드러내며 3개 스테이지를 헤쳐나가고, 마지막에 유니콘 형상의 보스와 맞섭니다.

| 5 | `BadDream_Stage1` | 챕터 2 - 어두운 꿈 1번째 스테이지 (2D) |

## 프로젝트 구조

게임 실행에 실제로 쓰이는 핵심 폴더 위주로 정리했습니다 (개발 중 생성된 산출물·백업·원본 자료 폴더는 생략).

```
Assets/
├─ Scenes/              씬 파일 (위 표 참고)
├─ Scripts/
│  ├─ BrightDream/       챕터 1(3D) 로직 - 스테이지 진행, 대사, 픽업, 체크포인트 등
│  │  ├─ Clues/          단서 조사·수집, 플레이어 상호작용
│  │  └─ Combat/         전투 - 보스 AI, 몬스터, 체크포인트 리스폰, 게임오버
│  ├─ 2d_scripts/        챕터 2(2D) 로직 - 플레이어 이동, 손전등, 컷신, 2D 보스전 등
│  ├─ UI/                공용 UI - 일시정지, 로딩 화면, 대사창/HUD 스킨
│  ├─ Player/, Interaction/, Hospital/   병실(현실) 파트 관련 로직
│  └─ MainMenuManager.cs, GameSettings.cs 등  전역 진입점/설정
├─ BrightDream/          챕터 1 아트·모델·머티리얼
├─ DarkDream/             챕터 2 아트 리소스
├─ Art/, Audio/, Prefabs/, Sprites/, Shaders/, Materials/   공용 리소스
└─ StreamingAssets/      오프닝 시네마틱 등 동영상 리소스
```

개발용 도구 스크립트(`tools/`)와 원본 작업 자료(`ArtSource/`)는 저장소 루트에 별도로 있으며, 게임 실행 자체에는 필요하지 않습니다.

## 핵심 기능

- **단서 수집·조사** — 챕터 1 탐색의 핵심 루프. 단서 4개를 모두 모으면 정화총이 드러납니다.
- **손전등 기반 은신/약점 시스템** — 숨어 있는 몬스터와 보스 약점은 손전등으로 비춰야 드러나고, 그래야 공격이 통합니다 (챕터 1·2 공통 컨셉).
- **대사·컷신 시스템** — 챕터별 스킨이 적용된 대사창, 인트로/보스 등장 연출.
- **보스전** — 챕터 1은 촉수형 보스(약점 파괴 방식), 챕터 2는 유니콘 보스. 몸통 접촉 시 데미지와 넉백이 함께 적용됩니다.
- **스테이지 진행 관리 + 체크포인트 리스폰** — 사망 시 씬을 처음부터가 아니라, 죽은 스테이지에 맞는 체크포인트(이전 스테이지 클리어 상태)에서 다시 시작합니다.
- **타임어택 타이머** — 챕터별로 제한 시간이 흐르며, 화면 상단에 표시됩니다.
- **UI/설정** — 일시정지 메뉴, 로딩 화면, 마우스 감도 등 공용 설정.

## 조작법

**챕터 1 - 밝은 꿈 (3D)**

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 조작 |
| Shift | 달리기 |
| Space | 점프 |
| E | 상호작용 (단서 조사, 아이템 습득) |
| 좌클릭 | 정화총 발사 |
| Esc | 일시정지 |

**챕터 2 - 어두운 꿈 (2D)**

| 키 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 (벽에 붙은 상태에서는 벽차기) |
| Shift | 대시 (스태미나 소모) |
| 마우스 | 손전등 조준 |
| E | 상호작용 |
| Esc | 일시정지 |

## 실행 방법

1. [Unity Hub](https://unity.com/download)에서 **Unity 6000.3.21f1** 버전을 설치합니다.
2. Unity Hub에서 이 저장소 폴더를 프로젝트로 엽니다.
3. `Assets/Scenes/MainMenu.unity`를 열고 Play를 누르면 시작 화면부터 플레이할 수 있습니다.

## 개발용 디버그 기능

챕터 1(3D) 씬의 `Player` 오브젝트에는 테스트를 위한 치트키가 붙어 있습니다 (에디터/개발 빌드에서만 동작).

| 키 | 동작 |
|---|---|
| F8 | 챕터 1 "Stage1 클리어" 상태로 즉시 이동 (정화총 줍기 전) |
| F9 | 챕터 1 "Stage2 클리어" 상태로 즉시 이동 (정화총 보유, 몬스터 정화 완료) |
| F10 | 보스 스테이지까지 진행 후 보스를 즉시 처치 |
| P | 자동 걷기 모드 (경로를 따라 자동 이동, 동선 확인용) |
