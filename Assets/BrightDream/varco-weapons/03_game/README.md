# 장난감 총 10종 — 게임용 (Dream1 / 밝은 꿈)

2026-09-21

`01_glb/` 의 VARCO 원본을 게임에 바로 쓸 수 있게 정리한 결과물이다.
**이 폴더가 납품본이다.** 원본은 재작업이 필요할 때만 쓴다.

## 규격 (10종 동일)

| 항목 | 값 |
|---|---|
| 폴리곤 | 3,000 tris |
| 정점 | 2,200 ~ 3,700 (용접됨) |
| 텍스처 | 1024 × 3장 (베이스컬러 / 노멀 / ORM) |
| 최장축 | 0.220 m |
| 원점 | 바닥 중앙 (Y = 0) |
| 포맷 | GLB |

**스케일 조정 불필요.** 임포트해서 그대로 놓으면 된다.
몹 0.900 m 기준 손에 드는 크기로 맞춰져 있다.

## 원본 대비

| | 원본 | 납품본 |
|---|---|---|
| 폴리곤 | 20,000 | 3,000 (-85%) |
| 텍스처 | 2048 | 1024 |
| 용량 합계 | 112 MB | 38 MB (-66%) |

3,000 에서도 실루엣 손상이 없다. 03 의 이빨, 07 의 고리 6개,
09 의 후프가 전부 뚫린 채로 유지된다. 비교 렌더는
`03_game/_preview/compare-20k-vs-3k.png` 참조.

펠트 스티치는 애초에 노멀맵으로 표현되므로 폴리곤 감축의 영향을 받지 않는다.

## 알려진 사항

**06 의 링 완드 구멍이 메워져 있다.** 열린 고리가 아니라 납작한 원반이다.
원본 생성 단계에서 발생한 것이라 감축과는 무관하다. 수정하려면 재생성하거나
Blender 에서 구멍을 뚫어야 한다.

**10 의 튤 돔이 불투명하다.** 안에 폼폼이 들어 있으나 보이지 않는다.
Unity 에서 해당 머티리얼만 알파를 주면 살아난다.

**뒷면이 앞면보다 단순하다.** 10종 공통. 단일 이미지 기반 생성의 구조적
한계로, 소스에 없는 면은 매끈한 덩어리로 채워진다. 총을 앞으로 들면
문제되지 않는다.

## 재현

```
blender -b -P 00_docs/cleanup_for_game.py -- <원본.glb> <출력.glb> 3000 1024 0.22
```

인자는 순서대로 목표 폴리곤 / 텍스처 크기 / 최장축(m) 이다.
