# 몹 에셋 5종 (펠트 크래프트 스타일)

레벨·벽면 에셋과 같은 v3 펠트-CG 톤으로 맞춘 적 캐릭터 5종.
VARCO 3D 로 이미지 → 메시 → 리깅 → 모션까지 뽑고, Blender 에서 한 파일로 합쳤다.

## 파일 구성

몹 1종당 GLB 파일 **1개**다. 그 안에 메시 + 스켈레톤 + 모션 2개가 모두 들어 있다.

| 파일 | 몹 | 공격 모션 | 사망 모션 | 용량 |
|---|---|---|---|---|
| `01_cotton_soldier.glb` | 검은 솜뭉치 병사 | 3.71s | 8.83s | 5.9MB |
| `02_patchwork_scarecrow.glb` | 천조각 허수아비 | 1.46s | 5.04s | 7.4MB |
| `03_button_knight.glb` | 단추눈 인형 기사 | 5.04s | 3.21s | 7.0MB |
| `04_yarn_spiderling.glb` | 털실 거미 인간 | 4.54s | 1.75s | 8.8MB |
| `05_felt_golem.glb` | 펠트 골렘 | 6.33s | 7.88s | 6.4MB |

`*_concept.png` 는 3D 변환에 쓴 원본 콘셉트 이미지다. 나중에 같은 몹을 다시 뽑거나
다른 색 변형을 만들 때 참고용으로 넣어 뒀다.

애니메이션 클립 이름은 다섯 종 모두 **`Attack` / `Death`** 로 통일했다.
AnimatorController 를 하나 만들어 5종에 돌려 쓸 수 있다.

## 스펙

- 메시 20,000 트라이앵글, 머티리얼 1개
- 텍스처 3장 (베이스컬러 / 노멀 / ORM), 각 1024×1024
- 스켈레톤 **본 23개**, 이름은 Mixamo 표준
  `Hips / Spine / Spine1 / Spine2 / Neck / Head /
   Left·RightShoulder / Arm / ForeArm / Hand /
   Left·RightUpLeg / Leg / Foot / ToeBase`
- 모션은 전부 **제자리 재생(in-place)** 이다. 이동은 게임 코드가 처리한다는 전제.
- 모델 높이 약 0.7 ~ 1.0 유닛. 배치할 때 게임 스케일에 맞춰 키우면 된다.

## Unity 로 가져올 때

1. GLB 를 `Assets/` 밑에 넣으면 Unity 가 알아서 읽는다.
2. Inspector → **Rig** 탭에서 Animation Type 을 **Humanoid** 로 바꾸고 Apply.
   본 이름이 Mixamo 표준이라 아바타 매핑이 자동으로 잡힌다.
3. **Animation** 탭에 `Attack` / `Death` 클립이 보인다. 공격은 Loop Time 끄고,
   사망도 끈다 (마지막 프레임에서 멈춰야 소멸 연출로 이어진다).
4. 텍스처는 ORM 한 장에 세 채널이 묶여 있다 (R=오클루전, G=러프니스, B=메탈릭).
   URP Lit 에 그대로 못 꽂으니 Metallic/Smoothness 로 변환하거나,
   펠트 재질이라 메탈릭이 0에 가까우므로 그냥 베이스컬러 + 노멀만 써도 충분하다.

## 소멸(디졸브) 연출에 대해

VARCO 애니메이션 카탈로그에는 **디졸브처럼 사라지는 모션이 없다.**
그래서 표준 방식대로 나눴다.

- **쓰러지는 동작** → 여기 들어 있는 `Death` 클립
- **사라지는 효과** → Unity 디졸브 셰이더 (노이즈 텍스처의 clip 임계값을 올려 깎아 내는 방식)

둘이 독립이라 `Death` 재생이 끝나갈 때쯤 셰이더 값을 0→1 로 올리면 된다.
몹마다 사라지는 색이나 속도를 다르게 주고 싶어도 모델은 건드릴 필요가 없다.
