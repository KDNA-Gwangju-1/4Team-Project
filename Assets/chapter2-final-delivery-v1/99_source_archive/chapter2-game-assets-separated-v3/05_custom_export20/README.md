- 입력: 사용자가 제공한 `소멸, 제자리 re-export1.png` ~ `export20.png`
- 프레임 크기: 384×384px
- 프레임 순서: 01 → 20
- 통합 시트: 7680×384px, 가로 20프레임
- 애니메이션 기준: 프레임당 200ms
- 출력 형식: 실제 알파 채널을 포함한 RGBA PNG
- 제거 대상: 남색 작업 배경, 뒤쪽의 흐린 얼굴 낙서와 붉은 배경 선
- 유지 대상: 보스, 동생, 유니콘, 가족 그림, 빛 조각, 검은 소멸 조각, 바닥 잔광
