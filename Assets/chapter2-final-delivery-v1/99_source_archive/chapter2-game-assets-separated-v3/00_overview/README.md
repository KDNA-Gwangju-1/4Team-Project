# 챕터 2 게임용 분리 에셋

- 투명 배경 PNG 컷아웃: 230개
- 배경 자체가 콘텐츠인 씬·배경 원본: 3개
- 모든 컷아웃은 RGBA PNG이며 투명 영역을 포함합니다.
- `01_final`: 현재 최종 사용 권장 에셋과 애니메이션 개별 프레임
- `02_all_generated_cutouts`: 과거 시안까지 포함한 생성 이미지의 개별 컷아웃
- `03_scene_backgrounds`: 배경 자체가 콘텐츠인 씬과 소용돌이 배경
- `99_source_sheets`: 분리 전 원본 합본 이미지
- 정확한 원본과 크기는 `00_overview/asset-manifest.csv`에서 확인할 수 있습니다.
